# 留白 · 日程规划 APP

计划被打乱时，帮你安排好接下来。

[项目仓库](https://github.com/LikLiiik/Liubai) · [手机试用反馈](https://github.com/LikLiiik/Liubai/issues/new/choose) · [自动检查](https://github.com/LikLiiik/Liubai/actions)

第一版实现放在 `mobile/`，使用 TypeScript、React Native、Expo SDK 58 和 Expo Router。网页是同一套 APP 的预览入口，手机端使用 SQLite 保存数据，网页端使用浏览器本地存储。

0.4.0 更新：新手教程直接展示可分别填写小时、分钟的双滚轮；周览练习复用正式任务卡片与 15 分钟吸附规则，可以实际拖动调整时间及日期。示例数据独立于个人日程。课表解析同时修正了课程名之后的备注识别，兼容括号外的周次/节次单位、全角数字及独立字段；失败时显示课程名、具体字段和有限的课表原文。同时为原生页面与弹窗接入键盘避让，当前输入框会按表单可见区域和键盘位置自动滚动，覆盖时间滚轮中的填写框。连续救场可为正在进行的临时事项续加时间；任务保存、跨夜日期、过期截止与重复套用保护同步修正，时刻与时长改为分别填写或滑动小时、分钟，并按各自范围限制输入；新手指引修订为第 11 版，加入自定义分类、顺手小事、完成后可选提前、撤销完成、昵称问候与卡片星标教学。这些更新已包含在 0.4.0 安卓包中。

当前开发修正（尚未打包）：重叠事件按占用区间合并计算时间预算与时间轴空档，避免固定与灵活事件重复扣减；周览并排重叠卡片隐藏星标。新增任务可选择自动安排或指定日期、开始时间，指定时间与固定属性分开，手动重叠仍须确认。修正带 `[实验]` 前缀的课程名解析；排课未识别的课程保留原文导入收集箱，支持重复导入与手动修改保护。首页问候按现实时间分五个时段，每个时段提供五组短句；重新进入首页或返回前台时更换，同一时段相邻两次不重复，操作任务时保持稳定。上次问候单独保存在本机，不随个人备份导出。新手指引更新为第 13 版，加入独立的问候切换演示。已发布的 0.4.0 安装包尚不包含本段修正。

## 已实现

- 今天：时间轴、今日重点、时间预算、完成/恢复任务。首页按手机本地现实时间显示昵称问候：00:00–04:59 凌晨、05:00–10:59 早间、11:00–13:59 午间、14:00–17:59 午后、18:00–23:59 晚间，各有五组问候和短句；重新进入首页、返回前台或切换时段时更换，同一时段避免相邻重复。任务数据更新不会触发更换；跨夜日程仍使用现实时间。昵称可在「我的」保存或清空，最多 20 个 Unicode 码点，去除首尾空白，未设置时只显示问候语；随本地数据和备份保存，返回前台刷新时间。
- 周览：课程表式周一到周日网格、切换周次、自适应/大卡片、全天范围；行高按屏幕可用高度调整，全天通过上下滚动查看。任务可跨天拖动，按 15 分钟吸附，边缘拖动会自动滚动。
- 固定事项默认锁定，二次确认后解锁一次拖动，松手后重新锁定；也可精确填写日期、时间。固定事项直接改时间时会确认目标位置。跨午夜事项在次日接续显示，拖动任一段会整体移动；手动重叠安排确认后可保存，超过硬截止日期的移动仍会被拒绝。有效移动写入回顾，可撤销。
- 手动并行安排：新增、编辑或周览调整时，同一时段可保留多件事，重叠前显示涉及事项并确认；取消保留原安排，周览中并排展示。授权只对本次位置和涉及事项生效，自动排程不会因此获得重叠权限。

周览以表格为主体，顶部只保留一行工具栏；说明、统计与显示选项收进右上角菜单，待安排任务默认收起。时间轴始终覆盖 00:00–24:00，浅灰区域表示偏好时段之外。手动拖动或精确改时间超出偏好时段时，确认后才会保存，取消则保留原位置；授权只对这次移动生效，自动排程继续遵循用户偏好。在“周览显示选项”中可切换大卡片，点击顶部收集箱图标展开待安排任务。网页可直接拖动，手机原生端长按后拖动；点击卡片也可精确填写日期与开始时间。原生手势仍需真机验收。
- 探索：统一提供收集箱与回顾两个入口；进入子页面后仍选中探索，并可从顶部返回。
- 收集箱：任务分类、未来任务、之前未完成的任务、安排到今天。默认仅工作、生活；可在收集箱或任务编辑中添加分类，新分类自动选中，筛选后新建待办沿用当前分类。分类随本地数据和备份保存，已有健康任务及撤销记录保留原分类。
- 任务管理：新增、编辑、删除、备注、预计时长、固定时间、优先级、截止日期。今天时间轴和周览事件卡片直接提供星标按钮，点亮设为重点，再点取消，今日重点列表随之更新；固定事项无需解锁，重点切换不改变时间、完成状态或调整足迹。周览星标独立于拖动及详情区域，重叠并排卡片隐藏星标，待安排卡片和未重叠的跨夜接续卡片同步显示；顺手小事继续保持无重点属性。独立 390×844 网页已验证两页互相切换重点、刷新保留、09:00→10:00 拖动保持重点、固定事项保持锁定，以及教程示例不改变真实任务。
- 顺手小事：在今天直接添加，或在添加表单中切换类型；仅填写日期与提醒时刻，无需时长。今天时间轴显示单一时刻和铃铛标记，周览显示虚线小卡片，可拖动或精确改提醒时间，移动可从回顾撤销。小事不占时间、不产生缓冲、不参与救场与自动排程；同一时刻可提醒多件小事。日程提醒开关同时控制任务与小事，表单支持主动申请通知权限；完成、删除或改时刻会取消或替换旧通知。手机尺寸网页已验证添加、时间轴显示、09:30→10:00 拖动、精确改为 10:17、重开保留、完成/恢复与教程隔离；实际手机通知送达仍需使用 0.4.0 安装包真机验证。
- 一键救场：临时有事、确认任务剩余时长、低精力模式、直接重新安排。
- 取舍预览：保截止时间、保结束时间、保今日重点；查看任务变化、延期和冲突后再套用。
- 完成后可选提前：今天勾选任务，或在周览详情勾选「此事件已完成」；先记录完成，有合适的后续灵活任务时显示提前预览。「保持原安排」不移动日程；「确认提前」才按原顺序填入空档，遵守偏好、缓冲和截止时间，不改变固定事项、小事、正在进行或未安排任务。回顾可撤销提前并保留完成状态；恢复为未完成若产生重叠，需明确确认。
- 撤销完成：今天的已完成事项、周览详情和回顾完成记录均可恢复为未完成。若曾因这次完成提前后续事项，先询问「一并取消提前」或「只撤销完成，保留提前」，并预览可恢复的时间。仅恢复本次提前且安排未再变更的事项，已编辑、已完成、已删除或原时段新增冲突的事项保留当前状态；恢复源事件产生重叠时再次确认。关联随本地数据保存，重开应用及调整足迹超过 20 条后仍可识别；兼容旧版仍保留的提前快照。
- 回顾：完成记录、调整足迹、撤销最近一次调整。若之后又改了任务，会阻止整批撤销，避免覆盖修改。
- 我的：昵称、日程偏好、灵活任务之间的缓冲、提醒、导出 JSON 数据、重看新手教程。原偏好设置链接会转到我的。
- 我的 → 课表导入：哈工大（深圳）本科课表的教务读取、学期日期确认、课程选择、冲突预览和确认导入。时间已识别的课程生成固定事项；时间不完整或有歧义的具名课程保留原文进入收集箱，不生成猜测日期。支持单双周、不连续周次、特殊课程延后 15 分钟、去重、合并更新和同步移除；手动修改与已完成记录受保护。示例仅在新手指引内演示，学校真实登录与当前接口仍需手机联调。
- 偏好时间按时、分两栏填写或滑动，拒绝非法字符和超范围值；结束提供当天／次日选择及快捷选项，最晚为次日 6 时 0 分。自动排程会使用跨夜时段，午夜后继续上一晚的安排；任务日期按实际日历保存，硬截止仍以截止日午夜为界。
- 手机本地通知的权限与排程接入；示例数据不会触发通知。通知需要真机验证。
- 收集箱空闲提醒：有安排的日子也会按连续空档推荐待办。我的中可独立开启，设置 30–120 分钟的连续空闲阈值；每天最多一条，用户确认后才安排，可暂缓该待办 3 天。
- 我的 → 检查更新：读取已发布版本、更新说明和安装包大小；Android 有新版时可直接打开下载，网页可获取最新安卓安装包。支持检查失败重试，不推荐降级。
- 常驻新手指引：首次使用自动进入 10 步教程，涵盖核心操作、独立教学演示、通知权限、更新和备份；支持稍后再看、继续和重看，在“我的”顶部长期保留入口。
- 时刻与时长分别呈现：时刻用两栏「时／分」，时长用「小时／分钟」的数量输入，不再提供整段冒号输入框。各栏可填写数字，也可展开对应滚轮。普通时刻小时 0–23、分钟 0–59；任务和救场时长 5 分钟–12 小时，缓冲 0–60 分钟，空闲阈值 30 分钟–2 小时。达到上限小时后，分钟同步收紧；空白或未完成的数字前缀离开时恢复最后有效值，不写入无效数据。旧版保存的时间字符串仍可读取。

首次打开会显示新手教程，示例仅存在于教程的独立教学卡片中，不写入个人日程。完成教程直接进入“今天”，首次使用从空白日程与真实时间开始；退出、重看或完成教程均不清空已有任务、偏好和提醒设置。旧版未改动的默认示例会自动转为空白个人日程；有新增、修改或调整记录时保留全部任务，避免丢失个人工作。

## 运行

环境：Node.js 24 LTS，npm。

```powershell
cd D:\日程规划APP\mobile
npm ci
npm run web
```

查看构建后的网页预览：

```powershell
npm run build:web
npm run preview
```

打开 http://127.0.0.1:4173 。预览服务只监听本机，不会公开发布。若端口占用，可先设置 `$env:PORT='4179'` 再启动；本次已打开的预览地址为 http://127.0.0.1:4179 。

手机开发：

```powershell
npm start
```

在匹配 SDK 58 的 Expo Go 中预览其支持的功能。完整原生验证需要开发包或安装包。

## 安卓手机试用

`eas.json` 的 `preview` 配置生成可直接安装的 APK，并自动递增构建号。当前已发布 0.4.0（构建号 7），包含独立新手教程、顺手小事、自定义分类、完成与撤销联动、昵称问候、外置重点星标，以及时间输入、键盘避让、连续救场和部分课表格式修正。保留连续空档待办提醒、手动并行安排和检查更新。安装包使用与上一版相同的签名，覆盖升级保留本地数据；新用户直接从空白个人日程开始。原生手势、系统通知及学校实际登录读取仍需手机试用验证。

- [GitHub 发布记录与校验文件](https://github.com/LikLiiik/Liubai/releases/tag/v0.4.0)。
- 手机下载二维码：`releases/留白-0.4.0-安卓下载二维码.png`（最新版本副本为 `releases/留白安卓下载二维码.png`）；校验信息：`releases/android-release.json`。

已核对 ZIP CRC、应用包名与版本、Hermes 程序资源、arm64 原生库、课表读取资源、APK v2 内容签名和上一版签名连续性。GitHub 公开下载文件的 SHA-256 与本地成品一致。实际设备的启动、手势和通知效果仍需试用验收。

在 `mobile/` 目录执行：

```powershell
npm run login:build
npm run build:android
```

浏览器中完成自己的 Expo 账号登录；首次构建按提示关联项目并使用托管的 Android 签名。构建完成后，在安卓手机浏览器打开构建页面提供的安装链接，下载 APK 并安装。此配置用于内部试用，不提交应用商店。安装后不需要电脑持续运行，也不依赖当前网页预览地址。

首次进入完成教程即可记录自己的日程，无需清空示例。示例操作可从“我的 → 新手指引”重看。打开提醒后，用几分钟后的真实任务检查系统通知。手机和网页各自保存本地数据，网页试填内容不会自动带到手机。

请保留同一个 Expo 项目和 Android 签名，以便后续更新覆盖安装并保留本地数据。卸载应用会移除任务，重要记录可在“我的”导出备份。

## 连续救场与任务保存

临时有事按实际当前时间预留，不推迟到偏好开始时间。当前自动生成的临时事项尚未结束时，再次选择临时有事会在原结束时间后追加所选分钟；原记录保留为同一事项，会议、课程和已完成事项继续参与冲突检查，累计超过 12 小时或超出当前规划日上限时拦截。兼容旧版生成的临时事项标识；结束后可新增另一条，不复用已有 ID。任务超时的数字始终表示用户确认的剩余时长，每次替换，不累加。

任务保存规则集中在 `mobile/src/taskDraft.ts`，新增自动任务依次找空位；无空位时仍保存为待安排，其他任务不变。手动重叠仍须针对本次位置确认。无具体开始时间的任务也校验所选日期与截止日期；过期截止不自动放宽到今天。今天、明天以及截止日期快捷项按实际日历计算，跨夜时单独提供“继续昨晚”。固定任务默认时间取当前实际时刻，避免深夜回退到 23:00。

## 检查更新与发布

发布流程由版本化元数据驱动：构建成品通过 `scripts/verify-apk.py` 校验包名、版本号、ZIP CRC、Hermes 资源、原生库、APK v2 签名与上一版签名连续性，再登记到 `releases/versions/<版本>.json`。推送版本标签后，GitHub Actions 先执行项目检查，再校验下载成品的字节数和 SHA-256，上传 APK、校验文件和更新记录，全部成功才公开 Release。已公开的不同资产不自动覆盖。最后验证公开下载并更新客户端使用的 `releases/android-release.json`；更新源不会提前指向未完成构建。

入口位于“我的 → 应用更新 → 检查更新”。仅在点击后联网读取本仓库 `main` 分支的 `releases/android-release.json`，不发送任务、偏好或登录凭证。对版本号按数字比较，Android 同版本时也比较可读取的构建号。开发版本高于已发布版本时不会显示降级下载；网页提供最新已发布安卓包的下载入口，iOS 不会显示 APK 安装按钮。连接或响应超过 12 秒会提示重试，离开页面则取消检查。

发布记录是客户端的更新源，开发中的 `app.json` 版本号、Git 标签或构建中的任务不会自动成为更新。每次用户明确要求统一打包后，再构建并校验 APK，确认包名和原签名，上传可下载的成品，最后更新并推送 `releases/android-release.json`。保留 `version`、`androidVersionCode`、`package`、`file`、`sizeBytes`、`sha256`、`downloadUrl` 和已通过的 `checks.archiveCrc/package/embeddedBundle`，可追加纯文本 `notes` 更新说明。下载地址支持本仓库 GitHub Release 的 HTTPS APK 资产及现有 Expo APK 链接，长期发布优先使用 GitHub Release 资产。

用户点击“下载更新”后通过系统浏览器下载，由安卓系统确认安装，不在应用内静默安装。SHA-256 在发布时记录并检查格式，当前下载交给浏览器，客户端不声称已校验用户下载文件。当前发布源指向 GitHub 的 0.4.0 APK，公开下载文件已完整下载并校验；手机版浏览器交接及覆盖安装仍需真机测试。

## 排程规则

固定事项与已完成事项不移动。不完整的任务即使原定时间已经过去，也不会被自动标记完成。灵活任务尽量整块安排；当前不自动拆分一个任务为多个时间块。

用户可在新增或编辑中指定固定时间，也可在周览中拖动或精确修改时间，在重叠确认中主动保留同时安排的多件事。固定事项解锁、非偏好时段和重叠安排各自需要相应授权；允许重叠也不能越过硬截止日期或移动已完成的任务。确认过程中目标时长或涉及事项发生变化时，重新确认；原有重叠任务仅改名称、备注时不重复要求重叠确认。

自动安排收集箱任务、空闲推荐、一键救场继续避开已有占用，不会套用手动重叠授权。用户已安排的固定重叠事项原样保留，其占用时间合并后供其他任务避让，不会仅因它们重叠就阻止整个排程；未固定的任务在自动重新安排时仍会分配到互不重叠的位置。教务课表批量导入保持原有冲突检查，不自动制造重叠课程。已在独立网页环境验证周览取消/确认、刷新保存、并排显示，以及新增和延长时长的重叠确认；原生拖动仍待统一打包后真机验收。

“保截止时间”允许在预览中接受最多延后结束 60 分钟，跨夜安排始终不超过次日 06:00。“保结束时间”和“保今日重点”不延长结束时间。今天或之前到期的任务放不下时会阻止套用，明确提示用户处理冲突；普通任务移到明天待安排。低精力模式把剩余可用时间的一半作为任务时长预算，不擅自缩短任务。

时间预算采用任务预计时长及灵活任务缓冲的估算，不是完成概率，也不是对连续时间块一定可用的保证。任务时长在回顾中始终标为“计划时长”，没有伪装成实际专注数据。

200 项规则测试、代码检查、类型检查及网页构建通过；0.4.0 安卓包已生成、签名校验并公开发布，iOS 安装包尚未生成。新手流程、时间输入、刷新保存与窄屏布局已通过网页检查。手机 SQLite 和通知已经接入；原生界面、系统权限、后台通知和真实教务读取仍需真机验收。数据只保存在当前设备/浏览器，清理应用数据会移除记录。

2026-10-20 发布前依赖审计仍有 3 项上游公告，传播为 26 条依赖链告警（19 条高风险、7 条中风险）：`braces`、`node-forge`、旧版 `uuid`。注册源当前 `braces@3.0.3` 与 `node-forge@1.4.0` 仍命中公告，`uuid@14.0.3` 超出当前工具链要求的主版本。自动修复建议跨主版本降级 Expo / React Native，本轮未强制替换 SDK 依赖，保留告警并继续跟进兼容补丁。APK 文件和签名校验不表示依赖告警已消失。详情见 [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)、[node-forge](https://github.com/advisories/GHSA-86w9-cpqp-85rv)、[uuid](https://github.com/advisories/GHSA-w5hq-g745-h8pq)。
